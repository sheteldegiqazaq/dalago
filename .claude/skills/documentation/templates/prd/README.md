## Maintenance Rules

- Add product scope changes to `product-overview.md`.
- Add requirements to `requirements.md`.
- Add domain models to `data-model.md`.
- Add implementation tasks to `implementation-plan.md`.
- Add AI rules to `agent-guidelines.md`.
- Add unresolved questions to `open-questions.md`.
