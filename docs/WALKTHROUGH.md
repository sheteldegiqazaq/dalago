# Сценарий показа продукта (3 минуты)

Сценарий повторяет то, что проверяет браузерный тест `frontend/tests/e2e/marketplace-flow.spec.ts`.
Все названия кнопок даны так, как они выглядят в интерфейсе (RU / KK).

## Подготовка (за 10 минут до показа)

1. Запустить базу, бэкенд и фронтенд (см. корневой README) или открыть https://dalago.vercel.app.
2. Локально пересоздать примеры данных: `cd backend && pnpm db:seed` — прошлые тестовые заявки удалятся.
3. Открыть две вкладки браузера:
   - вкладка А: `http://localhost:3000/kk` (покупатель);
   - вкладка Б: `http://localhost:3000/ru/try` в режиме инкогнито (поставщик).
     Токен хранится в localStorage, поэтому разные окна = разные аккаунты.
4. Проверить на `/ru/catalog`, какой режим ИИ показан: «Работает модель Claude» или
   «Резервный режим». Говорить то, что видно на экране.
5. Шрифт браузера 110–125%, чтобы было видно с дальних рядов.

## Ход показа

| Время | Действие на экране | Что сказать |
| --- | --- | --- |
| 0:00 | Главная `/kk`. Показать заголовок, переключатель **ҚАЗ / РУС** | «Магазину или кафе в Семее нужно найти местного поставщика. Фермеру — нового оптового покупателя. Мы проверяем гипотезу, что этот поиск сегодня отнимает много времени.» |
| 0:20 | Нажать **РУС** — весь интерфейс меняется. Прокрутить до блока «Регион в цифрах» | «Интерфейс полностью на казахском и русском. Здесь официальная статистика stat.gov.kz: население, валовая продукция сельского хозяйства, число субъектов МСП — с источником и датой.» |
| 0:40 | **Каталог** → в блоке «ИИ-поиск» нажать пример «Нужно 50 кг говядины для кафе в Семее до пятницы» | «Покупатель пишет обычным языком. ИИ понял: мясо, Семей, 50 кг, срок до пятницы — и применил фильтры. Товары берутся только из нашей базы, ИИ их не выдумывает.» |
| 1:00 | Открыть карточку «Говядина охлаждённая» → ссылку на поставщика | «Карточка: цена за кг, минимальный заказ, наличие, доставка. Пометка “Пример” — компании на площадке пока вымышленные.» |
| 1:15 | **Попробовать → Войти как покупатель** → **Новая заявка**: «Картофель для кухни», 250 кг → **Разместить заявку** | «Если готового товара нет, покупатель создаёт оптовую заявку. Статус — “Ждёт предложений”.» |
| 1:40 | Вкладка Б: **Войти как поставщик**. В кабинете — «Входящие заявки в ваших категориях» → **Ответить** → цена 138 ₸, доставка 2500 ₸ → **Отправить предложение** | «Фермер видит заявки в своих категориях и отвечает ценой, объёмом и сроком. Итог считается сразу.» |
| 2:05 | Вкладка А: обновить заявку → блок «Предложения поставщиков» → **Принять** → подтвердить | «Покупатель сравнивает предложения, отмечена лучшая цена. Принял — остальные отклонены автоматически, статус “Поставщик выбран”.» |
| 2:25 | Вкладка Б: **Кабинет → Объявление с ИИ** → вставить «Үржардан 40 литр қымыз сатамын, бағасы 1200 теңге» → **Заполнить форму** | «Поставщик пишет объявление одной фразой на казахском. ИИ заполнил категорию, цену, объём, город. Чего нет в тексте — остаётся пустым.» |
| 2:45 | **Карта региона**, затем **О проекте** (дорожная карта) | «Старт — Семей и область Абай, модель данных уже поддерживает другие регионы. Ищем пилотных партнёров среди хозяйств и кафе Семея.» |

## Запасной план

| Проблема | Что делать |
| --- | --- |
| Нет интернета / ключа Claude | Всё работает в резервном режиме на правилах. Сказать: «Сейчас работает резервный режим — он честно подписан на экране». |
| Бэкенд упал | `cd backend && pnpm start:dev`; база поднимается `pnpm db:local` (или Docker). |
| Примеры данных изменены прошлым показом | Локально `pnpm db:seed` пересоздаёт компании-примеры и сделки (~5 секунд). |
| Нужно показать без двух вкладок | После шага поставщика нажать **Выйти** и снова **Войти как покупатель** на `/ru/try`. |

## Аккаунты-примеры

Кнопки на `/try` входят в первый аккаунт-пример нужной роли без пароля
(`POST /api/auth/sample-session`). Для входа по email после `pnpm db:seed` пароль у всех: `dalago12345`.
В базе, заполненной прежней версией сида, адреса и пароль другие — входите кнопками на `/try`.

| Роль | Email | Компания |
| --- | --- | --- |
| Покупатель | `buyer@dalago.example` | Кафе «Ақ дастархан», Семей |
| Покупатель | `shop@dalago.example` | Магазин «Береке», Семей |
| Покупатель | `canteen@dalago.example` | Столовая «Курчатов асханасы» |
| Поставщик | `supplier@dalago.example` | КХ «Ертіс бақшасы» — овощи |
| Поставщик | `meat@dalago.example` | ТОО «Семей ет өнімдері» — мясо |
| Поставщик | `grain@`, `dairy@`, `honey@`, `orchard@`, `eggs@dalago.example` | Зерно, молочка, мёд, сад, яйца (все — аккаунты-примеры) |
