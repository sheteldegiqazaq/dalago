# Что подтверждает продукт

Карта утверждений о DalaGo → где это видно в продукте и чем подкреплено.
Пригодится для разговоров с партнёрами, инвесторами и пилотными компаниями.

## A. Актуальность и соответствие проблеме

| Поле | Содержание |
| --- | --- |
| Утверждение | Понятная региональная проблема: производитель в селе, покупатель в городе («Қала мен дала») |
| Где в продукте | Главная (блок «Қала мен дала»), «Открытые данные» (доля сельского населения 36,7%, валовая продукция сельского хозяйства), «О проекте» (гипотеза проблемы, план пилота) |
| Чем подкреплено | Официальные цифры stat.gov.kz с датой; сценарий «покупатель → заявка → поставщик → сделка» работает от начала до конца |
| Что усилит | 5–10 интервью с фермерами и кафе Семея, письмо о намерениях от одного пилотного партнёра |

## B. Техническое исполнение

| Поле | Содержание |
| --- | --- |
| Утверждение | Работающее приложение, а не макет: данные сохраняются, права проверяются, ошибки обрабатываются |
| Где в продукте | Весь сценарий сделки; кабинеты покупателя и поставщика; ИИ-объявление и ИИ-поиск; переписка; KK/RU |
| Чем подкреплено | PostgreSQL + Prisma с миграциями и CHECK-ограничениями; JWT и проверка роли и владельца на сервере; модульные тесты бэкенда и фронтенда (включая равенство ключей kk/ru), e2e-тесты API (включая отказ в доступе), браузерные тесты Playwright полного сценария; lint и сборка без ошибок |
| Что усилит | Включить ИИ с настоящим ключом Claude; показать `pnpm test:e2e` в терминале |

## C. Масштабируемость

| Поле | Содержание |
| --- | --- |
| Утверждение | Продукт можно вырастить за пределы Семея без переписывания |
| Где в продукте | «Карта региона» (регионы «Пилот» и «Следующий этап»); справочники регионов, городов и категорий в базе; «О проекте» (бизнес-модель и дорожная карта) |
| Чем подкреплено | Таблицы `regions`, `cities`, `categories` — новый регион добавляется данными, без кода; модульный монолит NestJS с отдельными модулями; переводы в словарях, готово к третьему языку |
| Что усилит | Оценка размера рынка по открытым данным с источниками; разговор с логистической компанией |

## D. Показ продукта

| Поле | Содержание |
| --- | --- |
| Утверждение | Аккуратный продукт, понятный показ за 3 минуты, честные ограничения |
| Где в продукте | Вход без регистрации одним нажатием (`/try`), примеры данных во всех статусах, баннер о примерах данных |
| Чем подкреплено | [WALKTHROUGH.md](WALKTHROUGH.md), [PITCH.md](PITCH.md), [ARCHITECTURE.md](ARCHITECTURE.md), [PILOT_PLAN.md](PILOT_PLAN.md); раздел «Честные ограничения MVP» на странице «О проекте» |
| Что усилит | Отрепетировать показ 3 раза с таймером; заранее ответить на вопросы из PITCH.md |

## Базовые требования к продукту

| Требование | Статус | Где |
| --- | --- | --- |
| Казахский и русский | Выполнено | Переключатель ҚАЗ/РУС во всех разделах; выбор сохраняется в cookie и профиле; тест равенства ключей словарей |
| Работающий MVP | Выполнено | Полный сценарий, подтверждён браузерными тестами |
| Доступность для пожилых | Выполнено в рамках MVP | Базовый шрифт 17px, контраст AA, кнопки от 44px, видимый фокус, подписи у полей, статусы текстом и иконкой, подтверждение необратимых действий, ссылка «Перейти к содержимому» |
| Открытые данные с источником и годом | Выполнено | `/open-data`: 7 показателей stat.gov.kz с периодом, датой публикации и ссылкой; каталог источников со статусом интеграции. Данные внесены вручную, API не подключён — это указано на странице |
