# Документация DalaGo

Пакет документов хакатона Republic Day Hackathon (Семей), трек «Қала мен дала».
DalaGo — название продукта, репозитория и кода.

## Порядок чтения

| Файл | Для кого | Что внутри |
| --- | --- | --- |
| [DEMO_SCRIPT.md](DEMO_SCRIPT.md) | Тот, кто показывает демо | Сценарий живого показа на 3 минуты по реальному интерфейсу |
| [PITCH.md](PITCH.md) | Спикер | Структура презентации на 8 слайдов с текстом для спикера |
| [JUDGING_CRITERIA.md](JUDGING_CRITERIA.md) | Команда перед защитой | Каждый критерий жюри → что показать и где это в продукте |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Технические вопросы жюри, разработчики | Стек, данные, права доступа, ИИ, демо-режим, ограничения, решения |
| [PILOT_PLAN.md](PILOT_PLAN.md) | Партнёры пилота | План пилота в Семее: участники, шаги, метрики, условия запуска |

Запуск проекта и демо-доступы описаны в корневом [README.md](../README.md).

## Правила поддержки

- Документы описывают то, что реально реализовано. Если функция только запланирована, это сказано прямо.
- Цифры о регионе — только официальные, со ссылкой на источник, периодом и датой публикации
  (см. `frontend/src/modules/open-data/model/constants/region-facts.ts`).
- Показатели площадки — демо-данные из сида, их нельзя выдавать за результаты пилота.
- После изменения сценария в интерфейсе обновите [DEMO_SCRIPT.md](DEMO_SCRIPT.md) и прогоните `pnpm test:e2e` во `frontend`.
